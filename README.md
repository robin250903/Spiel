# Ameisenalarm

Ein kleines Tower-Defense-Spiel im Browser: Ameisen, Käfer, Wespen & Co. wollen zum Picknick-Kuchen.

- 3 Karten: Sommerwiese (leicht), Sandstrand (mittel, zwei Wege), Terrasse (schwer, zwei kurze Wege)
- 7 Verteidiger, 8 Gegnerarten inkl. Elite-Krabbler und Ameisenkönigin
- Ziel: Welle 30, danach Endlosmodus
- Auto-Start für Wellen

Spielen: `index.html` im Browser öffnen.

# Ereignishorizont

Incremental Game: Du startest als Planck-Loch (21,8 µg) und frisst dich bis zu TON 618 (66 Mrd. Sonnenmassen) hoch.

- Kein Gebäude-Klicker: Echte Materie fliegt durchs Bild (Teilchenpaare, Staub, Asteroiden, Planeten, Sterne, Galaxien). Tippe Objekte an, um sie in dein Loch zu lenken; alles in deiner Einflusssphäre stürzt von selbst hinein.
- Sieben Ären mit eigener Materie, Akkretionsscheibe mit Eddington-Limit, Gezeitenkräfte, Jet-Regler, Kerr-Spin
- Fähigkeiten: Hawking-Ausbruch, Gravitationswelle, Penrose-Prozess, Quasar-Zündung
- Sonderobjekte: vagabundierende Sterne, fremde schwarze Löcher, Supernova-Schockwellen, Wurmlöcher
- Urknall mit Dunkler Energie, Raumzeit-Baum (21 Knoten) als eigenes Fenster, Größenvergleich auf der Bühne, Kosmische Leiter, Erfolge
- Speichert im Browser, Offline-Fortschritt, Test-Zeitraffer in den Optionen

Spielen: `ereignishorizont/index.html` im Browser öffnen.
