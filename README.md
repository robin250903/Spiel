# Ameisenalarm

Ein kleines Tower-Defense-Spiel im Browser: Ameisen, Käfer, Wespen & Co. wollen zum Picknick-Kuchen.

- 3 Karten: Sommerwiese (leicht), Sandstrand (mittel, zwei Wege), Terrasse (schwer, zwei kurze Wege)
- 7 Verteidiger, 8 Gegnerarten inkl. Elite-Krabbler und Ameisenkönigin
- Ziel: Welle 30, danach Endlosmodus
- Auto-Start für Wellen

Spielen: `index.html` im Browser öffnen.

# Ereignishorizont

Incremental Game: Du startest als Planck-Loch (21,8 µg) und frisst dich bis zu TON 618 (66 Mrd. Sonnenmassen) hoch.

- Währungen: Energie (aus Akkretion), Jet-Plasma (Überschuss über dem Eddington-Limit), Hawking-Quanten (beim Verdampfen), Dunkle Energie (Urknall)
- 17 Quellen von Vakuumfluktuationen bis zum Kosmischen Netz, Upgrades, Kerr-Spin, Raumzeit-Baum mit 21 Knoten
- Zufallsereignisse (Gezeitenzerreißung, Gasfilament, Supernova-Schockwelle, Wurmloch …), Kosmische Leiter mit echten Massen, Erfolge
- Speichert im Browser, Offline-Fortschritt, Test-Zeitraffer in den Optionen

Spielen: `ereignishorizont/index.html` im Browser öffnen.
